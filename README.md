## What this repository contains

Plain-English project summaries, design notes and an honest results record. Full implementation code, API credentials and raw session files are excluded from this public showcase. This documentation repository is not a runnable application.

The implementations are research and paper-execution systems. Live deployment, real-money trading performance and production readiness have not been established.
