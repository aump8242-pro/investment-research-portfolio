# Options Session Data

## Available material

The supplied archive contains 14 dated `.pkl` session files, with filenames ranging from 25 September to 15 October 2026. The archive contains no analysis program or README.

Only the archive inventory was inspected. The session payloads were not deserialised, so instrument coverage, Greeks calculations, sampling frequency and data quality have not been established.

## Possible extension

Build a documented workflow to validate session schemas, explain calculation inputs and create time-series visualisations of verified option-risk measures. This is proposed future work, not an implemented feature of the current showcase.

Raw session files are omitted from the public repository. No order-flow terminal implementation was established from the launcher filenames alone.
